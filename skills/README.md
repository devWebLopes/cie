## Como usar este catálogo

1. Identifique a categoria e o tipo de tarefa.
2. Localize a skill correspondente na tabela acima.
3. Leia o arquivo `.md` da skill **antes** de executar a tarefa.
4. Siga as regras e exemplos definidos na skill.

> ⚠️ **Regra rígida:** Nenhum agente deve criar componentes, estilos ou textos sem primeiro consultar a skill correspondente.
